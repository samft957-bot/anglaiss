# English Boost

Vocabulaire, grammaire et exercices guidés pour progresser en anglais à son rythme.

## Lancer
Ouvre `index.html` dans un navigateur. Il s’agit d’un site statique, sans installation ni compilation.

## Modifier les guides
Les aperçus de recherche sont dans `articles.js`. Les pages publiables complètes sont dans `guides/`. Mets ces deux endroits à jour ensemble. Les articles de ce prototype sont des brouillons : vérifie les affirmations, les liens, l’auteur et les dates avant publication.

## Publicités
`ads-config.js` a `enabled: false` par défaut et ne contient aucun sponsor. Le script `ads.js` n’appelle aucune régie externe. Si tu prévois un sponsor direct, vérifie d’abord l’entreprise, l’offre, le contrat et sa conformité ; les champs de configuration ne constituent pas une preuve de vérification ni un avis religieux. Pour une régie externe, ce code n’applique pas ses filtres.

## À finaliser avant déploiement
- Remplacer `example.com` dans les canoniques et `sitemap.xml` par le domaine réel.
- Compléter les informations exactes de l’éditeur et les politiques légales.
- Ajouter un contact fonctionnel et, le cas échéant, un mécanisme de consentement adapté aux services choisis.
- Tester les liens, les tailles d’écran, les performances et l’accessibilité.
- Vérifier la disponibilité du nom de marque.
